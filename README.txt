MAYOTTE PORITES-SYMBIODINIACEAE MANUSCRIPT
Analysis code and figure-generation repository

PURPOSE
This repository contains the R code and analysis inputs used to generate the
statistical analyses, tables and R-generated figures associated with the
Mayotte Porites–Symbiodiniaceae manuscript.

REPRODUCING THE R WORKFLOW
1. Download or clone the complete repository.
2. Open R/RStudio and set the working directory to the repository root.
3. Start a fresh R session.
4. Run:

   source("run_all.R")

UNIFRAC FIGURES AND ASSOCIATED TABLES

Run source("run_all.R") to regenerate all analyses, figures and associated
tables, including Figures S1, S2 and S5. After completion, run
source("record_session_info.R") to record the final software environment.

To regenerate only these figures and their associated tables, source the
corresponding scripts directly from the repository root:

source("figures/marker_concordance/plot_marker_tanglegrams.R")
source("figures/gunifrac_tree/plot_GUniFrac_type_profile_tree.R")
source("figures/phylogenetic_composition/plot_phylogenetic_composition.R")

S1 regenerates its tanglegram figure and the Mantel-test, entanglement and
dominant-type-profile tables in outputs/marker_concordance/tables/.
S2 regenerates its compartment figures and the dominant-profile table,
profile-colour table, sample/sequence trees and distance matrix in
outputs/gunifrac/diagnostics/. S5 regenerates its matched-composition figure.
Figures are saved in outputs/figures/.

These figures use untransformed post-MED relative abundances and generalized
UniFrac distances with alpha = 0.5 (d_0.5). S1 uses UPGMA sample clustering;
S2 uses Neighbor Joining within each compartment; S5 uses UPGMA coral sample
clustering. S1/S2 build k-mer/UPGMA sequence trees, whereas S5 uses DIV_tree.nwk
with its existing compartment filtering and rooting. The environmental rings
in S5 annotate the coral clustering and do not contribute to its distances.

REPOSITORY STRUCTURE
data/
  Canonical analysis inputs. Core SymPortal/metadata inputs are separated from
  analysis-specific marker-concordance and GUniFrac inputs.

analysis/
  General sequence statistics, thermal/density analyses, and the main
  community/multivariate workflow.

figures/
  Figure-specific R scripts for the post-MED composition, marker-concordance,
  GUniFrac tree and phylogenetic-composition figures.

manuscript_assets/
  Final externally produced manuscript assets, including Figure 1 from QGIS.

outputs/
  Destination for files regenerated by the R workflow. Generated outputs are
  not treated as source code and can be recreated with run_all.R.

run_all.R
  Runs the complete R workflow in sequence.

record_session_info.R
  Writes the current R/package environment to SESSION_INFO.txt.

SOFTWARE ENVIRONMENT
The repository does not require renv. For an archival record of the exact R
environment used for the final analysis, run:

   source("record_session_info.R")

after completing the workflow, then retain the generated SESSION_INFO.txt in
the archived/public repository.

NOTES ON VERSION HISTORY
Only the final analysis scripts are distributed here. Development copies,
superseded scripts, diff files and cleanup audit files are intentionally
excluded. Version history for the public repository can be maintained through
Git/GitHub.

Prior to public release, the analysis scripts were reorganised, commented and
edited for clarity and consistency. Generative AI tools were used to assist
with this editorial process. AI-assisted edits were limited to code
organisation, documentation and readability and did not intentionally modify
the analytical procedures, statistical methods, parameter settings or
calculations. The final workflows were rerun after restructuring to verify
successful execution of the complete analysis pipeline.

Further changes limited to comments or documentation do not constitute
analytical changes. Changes affecting filtering, transformations, statistical
models, permutation settings, random seeds or data used for plotting should be
treated as analytical changes and revalidated.
